# LittleDreams

אתר אלבום משפחתי בעברית, מותאם לטלפון. שני הורים יכולים להוסיף רגעים, ובני משפחה מוזמנים לצפייה.

## הפעלה מקומית

נדרש Node.js 24 ומעלה. אין תלויות להתקנה.

```sh
npm start
```

פותחים http://localhost:3000 ויוצרים חשבון ואלבום. הנתונים והקבצים נשמרים בתיקיית `data/`, שאינה עולה ל־Git. אין נתוני דוגמה או חשבונות ברירת מחדל.

## מה עובד

- הרשמה וכניסה עם סיסמה מוצפנת באמצעות scrypt ו־cookie מסוג HttpOnly.
- הוספת שם אירוע, תאריך, תיאור ועד חמישה קבצים, עד 20MB לאירוע.
- תמונות JPEG/PNG/WebP/GIF, סרטוני MP4/WebM ומסמכי PDF.
- ציר זמן, צפייה במדיה והורדת קבצים עם בדיקת הרשאות בשרת.
- הזמנה חד־פעמית ל־48 שעות; עד שני הורים עורכים, ומשפחה לצפייה ותגובות.
- תמיכה בחשבון ששייך לכמה אלבומים.

## גבולות הגרסה

זוהי גרסת פיתוח מקומית. השרת מאזין רק למחשב המקומי, ולכן קישורי ההזמנה אינם זמינים ממכשירים אחרים. עדיין אין שליחת דוא״ל, אימות דוא״ל, שחזור סיסמה, עריכת או מחיקת רגעים, הסרת בני משפחה או גיבוי אוטומטי. מסמכים מוגבלים כרגע ל־PDF.

לפני שימוש משפחתי אמיתי נדרשים אירוח עם HTTPS, cookie מאובטח (`COOKIE_SECURE=1`), גיבוי מוגן של מסד הנתונים והקבצים, בדיקת סוג הקובץ לפי תוכנו וסריקת קבצים, טיפול בבקשות וידאו גדולות והשלמת ניהול החשבונות והגישה. אין להעלות כרגע מידע רפואי או תמונות אישיות רגישות לסביבת הפיתוח.

הגדרות: `PORT` (ברירת מחדל 3000), `DATA_DIR` (תיקיית אחסון), `COOKIE_SECURE`.

```sh
npm test
```

תגובות לכל רגע: חברי האלבום וההורים יכולים להגיב (עד 2,000 תווים). שם הכותב נקבע בשרת לפי הקרבה והשם באלבום, למשל ״סבתא דורית״ או ״דודה לירז״; לחשבונות ותיקים ללא קרבה מוצג השם הקיים. רק חברי האלבום יכולים לקרוא ולהוסיף תגובות.

## הצטרפות המשפחה

קישור להזמנת משפחה פותח טופס של טלפון, שם וקרבה בלבד, עם תצוגה מקדימה של השם בתגובות. השליחה יוצרת חברות לצפייה ולתגובות באלבום המוזמן ומכניסה אליו ישירות. הקרבה והשם נשמרים לכל אלבום בנפרד. הזמנת הורה ממשיכה להשתמש בחשבון עם דוא״ל וסיסמה.

הגישה ניתנת באמצעות קישור ההזמנה האישי, החד־פעמי, שתקף ל־48 שעות. הטלפון הוא פרט קשר בלבד: אינו מאומת ואינו מאפשר כניסה, איחוד חשבונות או איתור אלבומים. מספר זהה אינו מקנה גישה לחשבון קיים. מספרי הטלפון אינם נשלחים בתגובות או ברשימת האלבומים. משתמש שכבר מחובר מצרף את האלבום לחשבון שלו; אין שינוי בהרשאות של אלבומים קיימים.

כניסת משפחה חדשה נשמרת ב־HttpOnly cookie ל־90 יום (Secure בענן, SameSite=Strict). בביקור חוזר באותו דפדפן נכנסים ישירות, גם דרך קישור ההזמנה שכבר נוצל. לאחר יציאה, פקיעת הכניסה, מחיקת נתוני הדפדפן או מעבר למכשיר אחר, נדרשת הזמנה חדשה; טלפון בלבד אינו משחזר כניסה. חשבונות קיימים עם סיסמה ממשיכים להשתמש במשך הכניסה הקיים של שבעה ימים.

בענן, `supabase/007-family-join.sql` מיושם אוטומטית אם טבלת פרטי המשפחה חסרה: מאפשר חשבונות מוזמנים ללא דוא״ל וסיסמה ומוסיף טבלה פרטית עם RLS, ללא גישה ישירה מהדפדפן. יש להחיל ולבדוק את ההגירה בסביבת בדיקה לפני פריסה. `npm test` כולל בדיקות HTTP מול SQLite ובדיקות של מטפל הענן עם מסד מדומה; הוא אינו מפעיל PostgreSQL אמיתי או משנה נתוני ענן.

## תמונות מהמוזמנים

מוזמנים יכולים לבחור ״יש לי תמונות מהרגע הזה״ ולשלוח תמונות לאישור. עד 10 תמונות יכולות להמתין לאישור לכל מוזמן בכל רגע; תמונות JPG/PNG/WebP/GIF עד 10MB לתמונה. רק השולח וההורים יכולים לצפות בתמונות הממתינות. ההורים רואים בראש האלבום בקשות עם שם השולח, תצוגה מקדימה, אישור ודחייה. אישור מוסיף את התמונה לרגע במסגרת מגבלת 10 קבצים ו־100MB לאירוע. מחיקת אירוע מסירה גם בקשות ממתינות; הן אינן מועברות לאירוע אחר.

בענן, `supabase/006-photo-requests.sql` מיושם אוטומטית בשרת אם הטבלאות חסרות, בתוך טרנזקציה עם נעילה בין מופעי השרת. אפשר גם להחיל אותו מראש דרך SQL Editor. הטבלאות פרטיות וללא גישה ישירה מהדפדפן. בדיקת ענן עם נתונים סינתטיים: הגדירו `SMOKE_BASE` והריצו `node scripts/check-photo-requests.mjs`. הבדיקה מוחקת את אירוע הבדיקה וקבציו; החשבונות הריקים נשארים מבודדים. בקשות חדשות מוצגות בכניסה לאלבום או ברענון; אין שליחת הודעות חיצוניות.
